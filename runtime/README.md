Pygbag 0.9.3 browser runtime, CPython 3.12 and pygame-ce 2.5.7.
Official source: https://github.com/pygame-web/pygbag and https://pygame-web.github.io/cdn/
Files are mirrored here so game startup does not depend on a second host.
The package-index CDN is set to this site; all runtime code is otherwise unchanged.
The startup script sets PYGPI=runtime/ to use the mirrored package index.
